# JK International Website — Product Image Asset Guide

This guide provides the exact folder paths, filenames, aspect ratios, and descriptions for all product and architectural photography on the JK International website.

---

## 1. Directory Structure

All images should be placed in `src/assets/images/` inside the respective subfolders:

```
src/assets/images/
├── hero/                          # Full-width 16:9 carousel slides
├── glass/                         # Architectural glass solutions (4:3)
├── aluminium/
│   ├── windows/                   # Aluminium window configurations (4:3)
│   ├── doors/                     # Aluminium door configurations (4:3)
│   └── systems/                   # Curtain wall, structural glazing, partitions (4:3)
├── upvc/
│   ├── windows/                   # uPVC window configurations (4:3)
│   └── doors/                     # uPVC door configurations (4:3)
├── factory/                       # Manufacturing plants, tempering furnace, CNC lines
└── projects/                      # Real installation photography
```

## 9. Zero-Broken-Image Strategy

All HTML templates have been configured with:
1. **Existing high-resolution fallbacks**: Every image tag currently points to verified existing project assets in `assets/images/`.
2. **`loading="lazy"`**: Enabled for all catalogue images below the hero fold to maximize Largest Contentful Paint (LCP) performance.
3. **Responsive image containers**: Handled via CSS `object-fit: cover` with fixed aspect ratios (`.product-thumb-wrap`), ensuring images never stretch, skew, or collapse.
